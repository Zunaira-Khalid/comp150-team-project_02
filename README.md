# comp150-team-project_02
COMP 150 Team Website

Our team website is built with two files: index.html and styles.css.

index.html holds the content of the page. It has a title at the top, a “Our Team” section with links to each TA’s personal website, and a “Pictures” section with three photos.

styles.css controls how the page looks. It sets the background color, text colors, and fonts, including a custom Google Font for the main heading.

The photos are uploaded directly into the repository, and GitHub Pages turns these files into a live website.
